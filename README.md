## 🛠 Open-source tools

| Project | What it does |
|---|---|
| [**nodecanvas-cli**](https://github.com/Primeer/nodecanvas-cli) | Read, search, lint and edit NodeCanvas graphs (behaviour trees, FSMs, dialogue trees) without opening Unity. A 120-node graph (~85 KB of JSON-in-YAML) is shown as ~10 KB of readable text. Atomic edit batches, byte-identical round-trips, Unity Editor verification. Ships as a **Claude Code plugin + skill** and an **MCP server** for Cursor, Codex and Gemini. Python, no dependencies, CI on 3.9–3.13. |
| [**NodeCanvas Usages for Rider**](https://github.com/Primeer/NodeCanvasForRider) · [Marketplace](https://plugins.jetbrains.com/plugin/35036-nodecanvas-usages) | NodeCanvas calls C# members by string name, so Rider marks them unused and a rename silently breaks graphs. This plugin brings graph references into **Code Vision, Find Usages and Rename**, plus inspections for broken references. Indexes a ~4000-asset project in ~0.3 s. C# (ReSharper SDK) + Kotlin. |
